EscapeAI — חדר בריחה מבוסס בינה מלאכותית
EscapeAI הוא משחק חדר בריחה אינטראקטיבי הכולל חמישה חדרים נושאיים, שרת Python וממשק משתמש ב־React. השחקן פותר חידות היגיון, סדרות מספרים, צפנים וקודים, ומודל AI בודק תשובות חופשיות ומחזיר משוב. המשחק מאפשר לבחור את אורך המסלול ומשנה את רמת הקושי בהתאם לביצועים.
תכונות עיקריות
- חמישה חדרים נושאיים ומסך ניצחון בסיום המשחק.
- בחירה של 5–15 חידות בתחילת המשחק; מעבר מחזורי בין חמשת החדרים.
- מאגר puzzles.json המכיל 45 חידות, תשובות, שלוש רמות קושי, רמזים והסברים.
- בחירת חידות דינמית תוך מניעת חזרה על אותה חידה במהלך משחק.
- בדיקת תשובות באמצעות AI עם פלט מובנה; התאמה מדויקת לתשובה השמורה יכולה להיבדק ישירות בקוד.
- Adaptive Difficulty: התאמת רמת הקושי לפי מספר ניסיונות, רמזים וזמן פתרון.
- מעקב אחר ניקוד, ניסיונות, רמזים, זמן והתקדמות במשחק.
- עד שלושה רמזים הדרגתיים מתוך מאגר החידות, לאחר ניסיונות שגויים חוזרים.
- ממשק כהה בסגנון חדר בריחה: אנימציות, אפקטים קוליים, מוזיקת רקע מסונתזת, עיצוב רספונסיבי וגלילה לראש העמוד במעבר לחידה.
- ניהול זרימת המשחק באמצעות LangGraph, כולל interrupt, חידוש באמצעות Command(resume=...) ו־Checkpointer.
- ניטור והערכת איכות הפרומפט באמצעות LangSmith.
הערת מימוש: המוזיקה, תיקון הרמזים וההתאמה למסכים קטנים תלויים בשילוב השינויים האחרונים בקבצי React והשרת. אין לראות בתיאור הזה אישור שכל התרחישים נבדקו מקצה לקצה.

איך המשחק עובד?
1. השחקן בוחר 5–15 חידות ומתחיל משחק חדש; השרת יוצר session_id.
2. המערכת בוחרת חידה מתוך puzzles.json לפי החדר ורמת הקושי הנוכחית, בלי לחזור על חידה שכבר נבחרה באותו משחק.
3. השחקן מזין תשובה חופשית דרך React.
4. תשובה זהה לתשובה השמורה יכולה להתקבל ישירות; תשובות אחרות נבדקות באמצעות מודל AI שמחזיר משוב מובנה.
5. תשובה שגויה מגדילה את מספר הניסיונות. לאחר כל שני ניסיונות שגויים ניתן רמז נוסף, עד שלושה רמזים לחידה.
6. תשובה נכונה מוסיפה ניקוד, מעדכנת את ההתקדמות ואת נתוני הביצוע, ומפעילה את מנגנון התאמת הקושי.
7. המערכת עוברת לחידה הבאה. לאחר חדר 5 חוזרים לחדר 1 עם חידה חדשה, עד להשלמת מספר החידות שנבחר.
8. בסיום מופיע מסך ניצחון עם נתוני המשחק.
חשוב: קבלת רמז אינה פותחת את החדר אוטומטית. כדי להתקדם יש להזין תשובה נכונה.

שימוש ב־LangSmith
הערכה אוטומטית ושיפור פרומפט באמצעות LangSmith
מטרת הניסוי
בפרויקט EscapeAI ביצענו הערכה אוטומטית של מנגנון בדיקת התשובות באמצעות LangSmith, במטרה לשפר את דיוק המודל בזיהוי תשובות נכונות, שגויות וחלקיות.
גרסה ראשונה — Before
בגרסה הראשונה הפרומפט כלל הוראות כלליות לקבל תשובות בעלות משמעות שקולה ולדחות תשובות שגויות או חלקיות.

עם זאת, לא הוגדר במפורש כיצד יש לבדוק קודים מספריים המורכבים ממספר ספרות, או כיצד להתמודד עם תשובות המכילות כמה אפשרויות.

תוצאות הניסוי: 79% דיוק — 21 מתוך 27 בדיקות הצליחו.
גרסה משופרת — After
בעקבות זיהוי שגיאות בגרסה הראשונה, שיפרנו את הפרומפט והוספנו הוראות מפורשות:
- קבלת תשובה אחת נכונה גם כאשר היא מנוסחת בחוסר ביטחון, למשל אולי 48.
- דחיית תשובות המכילות כמה אפשרויות, למשל 48 או 50.
- זיהוי מספרים הכתובים במילים, למשל ארבעים ושמונה במקום 48.
- זיהוי קודים המשלבים ספרות ומילים, למשל אחד שלוש 4 שניים במקום 1342.
- בדיקה שכל הספרות בקוד מופיעות בסדר הנכון, ללא השמטות.
תוצאות הניסוי: 100% דיוק — 27 מתוך 27 בדיקות הצליחו.

השיפור הכולל: 21 נקודות אחוז.
התוצאות מתייחסות למאגר ההערכה המסוים של 27 דוגמאות; הן אינן מבטיחות דיוק של 100% בכל חידה או תשובה עתידית.

תובנה מתוך ניתוח Trace
במהלך ניתוח ה־Traces ב־LangSmith זיהינו שגיאה בגרסת Before.

התשובה הנכונה לחידה הייתה 1342, אך השחקן הזין:
אחד שלוש ארבע
תשובה זו מייצגת את הרצף 134 בלבד, ולכן היא חלקית וחסרה בה הספרה האחרונה.

למרות זאת, המודל החזיר:
is_correct = True
בעוד שהתוצאה הצפויה הייתה:
is_correct = False
ב־LangSmith התקבל עבור הבדיקה ציון accuracy = 0.

בגרסת After הוספנו לפרומפט הוראה מפורשת:
For a multi-digit ACCESS CODE,
the order and number of digits must match exactly.
התקנה והרצה
### הפעלת המשחק דרך הטרמינל (ללא React)

בנוסף לממשק הגרפי, ניתן להפעיל את EscapeAI ישירות דרך הטרמינל באמצעות `main.py`.

מתוך תיקיית `backend`, לאחר התקנת התלויות והגדרת מפתח OpenAI:

```powershell
python main.py
```

המשחק מציג חידות, מקבל תשובות חופשיות, מפעיל את מנגנון בדיקת התשובות ומציג משוב, ניקוד והתקדמות.

שתי אפשרויות ההפעלה — טרמינל ו־React — משתמשות באותו מנוע LangGraph.
דרישות מקדימות
- Python 3.12 או גרסה תואמת.
- Node.js ו־npm.
- מפתח API של OpenAI.
שלב 1 — הרצת השרת
פתחו טרמינל בתיקיית backend:
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
אם אין קובץ requirements.txt, יש ליצור אותו לפי התלויות בפועל. בין הספריות הדרושות: fastapi, uvicorn, python-dotenv, langchain-openai, langchain-core, langgraph ו־`langgraph-checkpoint` (בהתאם לגרסאות המותקנות).

צרו קובץ .env בתוך backend:
OPENAI_API_KEY=your_openai_api_key_here
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your_langsmith_api_key_here
LANGSMITH_PROJECT=EscapeAI
משתני LangSmith נדרשים רק אם רוצים להפעיל ניטור וניסויים. יש לטעון את .env לפני יצירת ChatOpenAI, למשל:
from pathlib import Path
from dotenv import load_dotenv

load_dotenv(Path(__file__).resolve().parent / ".env")
הפעילו את השרת:
python -m uvicorn api:app --reload
ממשק Swagger: http://127.0.0.1:8000/docs.
שלב 2 — הרצת צד הלקוח
פתחו טרמינל נוסף מתוך תיקיית הפרויקט הראשית:
cd frontend
npm install
npm run dev
פתחו בדפדפן את הכתובת ש־Vite מציג. ודאו שכתובת ה־API בצד הלקוח תואמת לשרת FastAPI וש־CORS מאפשר את כתובת ה־Frontend.
